# PostgreSQLearning
해당 레포지토리는 포스트그레스 SQL을 더불어 백엔드, ORM을 활용한 방식도 제공합니다.

mac 홈브루 기준,
<code>chmod +x init.sh</code>를 하여 <code>./init.sh</code>를 직접 실행시키거나, 직접 아래의 과정을 따르세요.
포스트그레스 SQL을 먼저 설치합니다.
```bash
brew services start postgresql@18
```

포스트그레스 서버를 백그라운드에서 실행합니다.
```bash
brew services start postgresql@18
```
